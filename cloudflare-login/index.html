TECHNICAL HANDOVER

The login is
more than a form.

The real RaceDay login runs through the ASP.NET Core MVC `AccountController`, a separate REST API, ASP.NET Identity, secure cookies, CSRF protection and a SQL Server database.

Cloudflare Pages hosts this static login preview. The original C# authentication code, live API and persistent database have not been deployed to this Pages site, so real registration and sign-in remain unavailable.

This preview is for peer review, not evidence of functional hosted authentication.
